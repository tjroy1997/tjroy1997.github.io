# Mobile Photography

Upload your images to this folder. They will automatically appear under **Mobile Photography** in [the website Gallery](https://tjroy1997.github.io/#mobile-photography).

## Upload steps
1. Open this folder in GitHub and select **Add file > Upload files**.
2. Choose JPG, JPEG, PNG, WebP, GIF, or AVIF images. Convert HEIC photos to JPG for wider browser support.
3. Commit the upload to the main branch. Reload your gallery after the GitHub Pages update.

## File names and display order
Use descriptive filenames, for example: 01-houston-sunset.jpg, 02-rainy-day.webp.
Images are shown in natural filename order. Filenames become captions and image descriptions.

## Privacy
This GitHub repository is public. Only upload photographs you have permission to publish.
Large images should be resized or compressed for better mobile performance.

## How the gallery works
The gallery reads the public contents of this folder using the GitHub Contents API, so newly uploaded photos can be displayed without editing HTML. API rate limits or blocked requests may temporarily prevent photos from loading.
