Tidyverse & Simple Mediation

These short lessons use the tidyverse (dplyr + ggplot2) for cleaner code and show how to run a very simple mediation analysis. Install the packages once with install.packages(c("tidyverse", "broom")). The example is a tiny fictional study of practice, confidence, and quiz score.

  1. Tidy a small dataset
  2. Summarize and plot with dplyr & ggplot2
  3. Simple mediation (practice → confidence → score)
R · Advanced 1

Tidy a small dataset

Imagine six students. Each practiced for a different number of minutes, reported how confident they felt (1–10), and then took a short quiz (0–20). We will keep the data in a tidy data frame so later steps stay simple.

library(tidyverse)

students <- tibble(
  student = c("A","B","C","D","E","F"),
  practice_min = c(10, 20, 15, 30, 25, 40),
  confidence = c(4, 6, 5, 8, 7, 9),
  quiz_score = c(8, 12, 10, 16, 14, 18)
)

print(students)

Check your result. You should see a 6-row table. Student F practiced the longest (40 min) and scored the highest (18).

Try it. Add a new column called practice_hours that divides minutes by 60. Which student practiced more than half an hour?

Summarize and plot with dplyr & ggplot2

Tidyverse verbs make summaries and plots easier to read. Here we calculate the mean quiz score and draw a simple scatterplot of practice time versus quiz score.

# Mean quiz score
students %>%
  summarise(mean_score = mean(quiz_score))

# Scatterplot
ggplot(students, aes(x = practice_min, y = quiz_score)) +
  geom_point(size = 3, color = "#17628b") +
  geom_smooth(method = "lm", se = FALSE, color = "#b05020") +
  labs(title = "Practice minutes and quiz score",
       x = "Practice (minutes)", y = "Quiz score") +
  theme_minimal()

Check your result. The mean quiz score is 13. The points rise from left to right — more practice tends to go with higher scores in this tiny sample.

Try it. Change the plot so the x-axis is confidence instead of practice minutes. Does the upward pattern still appear?

R · Advanced 3

Simple mediation (practice → confidence → score)

Mediation asks: does practice improve the quiz score partly because it raises confidence? We run three ordinary linear models and look at the numbers in plain language.

library(broom)

# 1. Total effect: practice → score
total <- lm(quiz_score ~ practice_min, data = students)
tidy(total)

# 2. Practice → confidence (the mediator)
a_path <- lm(confidence ~ practice_min, data = students)
tidy(a_path)

# 3. Practice + confidence → score
full <- lm(quiz_score ~ practice_min + confidence, data = students)
tidy(full)

How to read it (simply).

  • The coefficient of practice_min in the first model is the total effect.
  • The coefficient of practice_min in the second model shows how much confidence rises with each extra minute of practice (path a).
  • In the third model, the coefficient of confidence is path b. The coefficient of practice_min that remains is the direct effect. The indirect (mediated) effect is roughly a × b.

In this tiny example the numbers will be large because the sample is only six students — the goal is to see the pattern, not to draw real conclusions.

Check your result. You should see positive coefficients for practice in all models and a positive coefficient for confidence in the full model. The practice coefficient gets smaller once confidence is added — that is the classic mediation pattern.

Try it. Print the three models with summary() instead of tidy(). Which number is the easiest to explain to a friend?
